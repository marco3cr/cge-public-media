# cge-public-media

Assets públicos del Content Growth Engine. Se sirven con GitHub Pages para que las APIs de las redes sociales puedan descargarlos por HTTPS (Instagram solo acepta imágenes desde una URL pública).

Solo contiene imágenes ya aprobadas para publicarse. No contiene código, secretos ni archivos privados.
